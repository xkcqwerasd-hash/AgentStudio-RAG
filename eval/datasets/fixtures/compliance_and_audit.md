# 企业数据安全分级与审计合规指南

## 1. 数据分类分级原则与标准
为满足企业级数据合规与金融监管要求，系统遵循中国网络安全法及 GDPR 规范，对平台内产生与流转的所有数据实行四级分类分级制度：
公开级（Public）：系统公开技术手册与开源文档；
内部级（Internal）：仅限企业内部员工访问的常规知识库；
机密级（Confidential）：包含业务细节的技术规格文档及用户私有多轮对话数据，必须实施落盘加密存储；
绝密级（Restricted）：核心业务机密与敏感凭证，严禁离开隔离专用内网环境。

## 2. 个人身份信息脱敏过滤要求
所有外部用户输入文本在进入语义向量化（Embedding）模型及向量知识库存储前，必须经过前置数据清洗脱敏管道。
脱敏管道结合正则表达式规则集与轻量化命名实体识别（NER）技术，对个人身份信息（PII）进行强制遮蔽脱敏：
涉及用户姓名、居民身份证号、手机号码、企业银行卡号及电子邮箱地址等核心隐私信息，必须自动替换为掩码字符（如将手机号脱敏为 138****1234）。
未通过合规校验脱敏的敏感数据严禁存入持久化向量数据库或提供给第三方外部模型。

## 3. 审计日志与追踪数据留存规范
为确保系统所有行为具备可追溯性与法律合规证据力，系统对运维操作与模型调用实施全生命周期日志留存：
管理员后台敏感操作记录、智能体多步执行 Trace 元数据以及安全风控拦截事件，必须在冷备份存储中保存不少于 180 天。
留存期满 180 天的审计日志，统一转储至基于 WORM（单写多读防篡改）策略的对象存储归档桶中，满足长期审计调阅要求。

## 4. 密钥管理与安全存储规范
系统对所有涉及外部大模型供应商的 API Key、内部数据库登录密码及 JWT 数字签名私钥实施集中安全托管。
核心凭证与密钥在数据库中必须使用 AES-256-GCM 算法进行高强度静态落盘加密，加密密钥由环境变量独立注入，严禁硬编码。
密钥的最长使用生命周期为 90 天，系统将在密钥服役满 75 天时向管理员发送自动轮转告警通知，逾期强制要求更新。
