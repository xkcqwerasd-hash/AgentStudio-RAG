# AgentStudio-RAG — 5~8 分钟完整演练演示实操指南 (Demo Guide)

> **版本**：`v1.3.0-RC1` (`RC-Phoenix-2026`)  
> **适用对象**：产品经理、解决方案架构师、技术评审专家与客户售前演示人员。  
> **演练目标**：在 5~8 分钟内，以行云流水的实操连贯展示 AgentStudio-RAG 的 8 大核心亮点，展现从个人极简体验到企业级安全交付的完整产品力。

---

## 一、演示前准备工作 (Pre-demo Preparation)

### 1. 环境准备检查清单
- [ ] 确保 Docker 容器栈处于运行状态：`docker compose -f docker-compose.local.yml ps`（或 Server 模式 `docker compose ps`）。
- [ ] 确保浏览器打开 `http://localhost:8080`，建议使用 Chrome / Edge 隐身窗口以展示纯净初始状态。
- [ ] 准备 2 份测试文件（建议放置于桌面方便拖拽）：
  - **文件 1（知识库测试文档）**：`企业核心系统架构规范_2026.txt`（包含特定版本号或代号，如 `代号：RC-Phoenix-2026，核心技术采用三态路由架构`）。
  - **文件 2（单会话临时附件）**：`2026年Q3财务简报.txt`（包含明确数字，如 `2026年Q3总营收为 12.8 亿元，同比增长 45.2%`）。

## 二、标准化 8 步演练实操脚本 (Step-by-Step Script)

### Step 1: 首页工作台与系统架构概览（0.5 分钟）
- **操作动作**：打开浏览器访问 `http://localhost:8080`。
- **解说词**：
  > “各位评委/专家好，现在展现在大家眼前的是 **AgentStudio-RAG 智能知识问答系统** 的现代化工作台。  
  > 整个界面采用极简优雅的企业级交互风格，支持双部署架构：此时右上角显示的是 **‘本地免登模式’**，专为个人开发者和私密研究设计，基于 SQLite 实现开箱即用，免除繁琐的注册登录；同时系统支持一键无缝切换至基于 PostgreSQL 16 的 **‘企业多租户 Server 模式’**，共用同一套底层业务引擎。”

---

### Step 2: 多模型管理与网络连通性验证（0.5 分钟）
- **操作动作**：
  1. 点击左侧导航栏 **「模型管理」**。
  2. 观察列表中已激活的 `DeepSeek-Chat` 模型。
  3. 点击右侧操作列的 **「连通性测试」** 按钮。
- **预期现象**：弹出绿色轻提示 `连接测试成功！网络延迟: 1822ms`。
- **解说词**：
  > “系统支持多模型热插拔管理，兼容 OpenAI 规范、DeepSeek 以及本地私有化的 Ollama 集群。  
  > 所有的 API 凭据在落库前均经过主加密密钥的高强度对称加密保护。通过内置的连通性探测功能，运维人员可以在毫秒级掌握各模型提供商的网络响应健康度。”

---

### Step 3: Direct LLM 极速直答与意图路由（0.5 分钟）
- **操作动作**：
  1. 点击导航栏回到 **「对话工作台」**，新建一个对话。
  2. 在输入框输入通用问题：`“Python 中如何安全且高效地读取一个大文件？请用一两句话总结。”`，按下回车发送。
- **预期现象**：
  - 系统以极高流速（首字响应 < 500ms）逐字打印出流式 Markdown 回答。
  - 回答底部执行状态显示 `执行模式: Direct LLM (0 检索开销)`。
- **解说词**：
  > “大家注意，针对日常通用常识、问候或纯代码咨询，系统内置的 **智能意图路由** 会自动将其判定为 Direct 路径，完全绕过向量和关键词检索，实现 **0 检索开销、超低延迟的极速直答**，极大节约企业算力成本。”

---

### Step 4: 知识库创建、Workflow RAG 混合检索与真实引用溯源（1.5 分钟）
- **操作动作**：
  1. 点击左侧 **「知识库管理」**，点击右上角 **「新建知识库」**，输入名称 `企业核心规范库`。
  2. 点击进入新建的知识库，点击 **「上传文档」**，拖入准备好的 `企业核心系统架构规范_2026.txt`。
  3. 观察文档解析流水线：从 `PENDING` 秒级流转至 `COMPLETED`，显示生成的分块数量。
  4. 回到对话工作台，在对话顶栏绑定刚才创建的 `企业核心规范库`。
  5. 提问：`“AgentStudio-RAG 的内部版本代号和核心技术分别是什么？”`，回车发送。
- **预期现象**：
  - 系统生成严谨回答：`“依据企业核心规范，系统内部版本代号为 RC-Phoenix-2026 [Ref-1]，核心技术采用三态路由架构...”`。
  - 答案中带有高亮的 `[Ref-1]` 引用角标。
  - 点击 `[Ref-1]`，右侧展开原文溯源抽屉，清晰显示原始来源文件名、物理页码、分块 ID 与精准高亮的原文字段。
- **解说词**：
  > “这是系统的核心基石：**确定性 Workflow RAG 引擎**。它通过 **Dense 语义向量 + BM25 稀疏检索** 双路召回，并经过 **RRF 倒数排名融合** 与 **Cross-Encoder 深度重排序**，实现了绝对可靠的企业专有知识召回。  
  > 最关键的是，每一条回答都有据可查，点击引用标记即刻展开物理页码原文，彻底根除了大模型的幻觉编造。”

---

### Step 5: 单会话临时附件上传与跨页即时问答（1.0 分钟）
- **操作动作**：
  1. 在当前会话输入框左侧点击 **「📎 附件上传」** 图标。
  2. 选择上传 `2026年Q3财务简报.txt`。
  3. 输入提问：`“根据刚才上传的财务简报，2026年Q3的营收数据是多少？同比增长了多少？”`，回车发送。
  4. 提问完成后，点击输入框下方的附件标签上的 **「删除」** 图标将其移除。
- **预期现象**：
  - 系统准确回答：`“根据简报，2026年Q3总营收为 12.8 亿元 [Ref-1]，同比增长 45.2% [Ref-1]。”`。
  - 删除附件后，该附件不再参与后续上下文检索；且至知识库页面检查，该文档从未污染主知识库。
- **解说词**：
  > “很多时候用户只是想临时探讨一份合同或备忘录，如果每次都传进知识库，会迅速导致知识库混乱。  
  > AgentStudio-RAG 设计了 **单会话临时附件引擎**，基于内存高效解析，仅在当前会话的上下文窗口内检索，用完即删，与公共知识库实现严格的物理与逻辑隔离。”

---

### Step 6: 跨会话长期记忆自动提取与智能注入（1.5 分钟）
- **操作动作**：
  1. 在对话框中向 AI 输入一句带有鲜明个性化背景的话：`“你好，我叫王博士，在金融科技领域从事高频量化交易系统架构设计已有 10 年，主要技术栈是 C++ 和 Python。”`。
  2. AI 礼貌确认接收信息。
  3. 点击 **「新建对话」**（完全开启一个全新的空白对话，不携带历史上下文）。
  4. 在新会话中提问：`“我想在团队内部组织一次针对核心开发者的技术进阶分享，请为我量身定制一份分享主题和提纲。”`。
- **预期现象**：
  - AI 的回答极具针对性：主动结合“高频量化交易架构师王博士”的身份，推荐如 `“基于 C++ 与 Python 的高频量化交易撮合引擎极致性能优化实战”` 等高度契合专业背景的定制大纲。
  - 打开左侧导航栏 **「长期记忆」** 面板，清晰展示系统已自动提炼并记录的 `USER_PROFILE` 事实条目，支持用户直接在线编辑或注销删除。
- **解说词**：
  > “大家可以看到，系统具备真正的 **跨会话长期记忆能力**。它在后台自主提炼高浓缩用户画像与约束事实，并在严格受控的 Token 预算内动态注入新对话，避免了繁琐的重复背景说明，提供了连贯且充满尊崇感的个性化体验。”

---

### Step 7: LangGraph 多步推理 Agent 与自主工具调度（1.5 分钟）
- **操作动作**：
  1. 在对话顶栏将执行模式从 `Workflow` 切换为 `Agentic (LangGraph)`。
  2. 输入多步复合推理指令：`“请先在企业核心规范库中查询版本代号，然后结合你掌握的 Python 工具，分析该代号在 2026 年度研发规划中的交付优先级，并输出结构化总结报告。”`。
  3. 观察界面实时输出的思考步骤展开折叠面板。
- **预期现象**：
  - 界面呈现清晰的 Agent 思考过程：
    - Step 1: `Action: call_knowledge_base_retriever(query='版本代号')`
    - Step 2: `Observation: 检索到 RC-Phoenix-2026`
    - Step 3: `Thought: 已获取代号，结合交付优先级标准进行推演分析...`
  - 最终给出结构化的综合分析报告。
- **解说词**：
  > “当面对需要‘检索后计算’、‘多步自查纠错’的复杂企业业务时，系统自动启动 **LangGraph Agent**。它以状态循环图为底层驱动，自主决策何时调用知识库检索器、何时进行多工具协同，实现了从简单的‘检索匹配’向深度的‘自主问题求解’的跨越。”

---

### Step 8: Server 模式多租户权限与水平越权隔离（1.0 分钟）
- **操作动作**（通过预先准备好的两个浏览器窗口或无痕模式）：
  1. 打开无痕窗口，以普通用户 `Alice` 登录系统，展示 Alice 拥有的私密对话 `Alice-投资备忘录`。
  2. 切换到主窗口，以另一个普通用户 `Bob` 登录。
  3. 展示 Bob 的会话列表空空如也，看不到任何 Alice 的数据。
  4. （可选进阶演示）在 Bob 登录状态下，尝试通过浏览器地址栏直接访问 Alice 会话的 URL，系统直接返回 404 拒绝。
- **解说词**：
  > “最后，我们来看系统的生产级安全底座：在 Server 模式下，系统执行严格的多租户 RBAC 权限隔离。  
  > 无论是对话、知识库、附件还是个人长期记忆，每一个端点都由底层 IDOR 防御机制牢牢锁死。任何越权探测直接返回 404，确保不同部门与租户之间的数据资产具备金融级的安全屏障。”

## 三、演示应急预案 (Troubleshooting Checklist)

| 潜在意外情况 | 快速应对与修复操作 |
| :--- | :--- |
| **大模型响应偶发超时** | 保持冷静，点击对话输入框旁边的「重试」图标，或直接展示之前预热生成的问答历史。 |
| **网络波动导致连通性测试变红** | 检查本地梯子或代理是否阻断了 `api.deepseek.com` 域名，或切换备用 OpenAI Key。 |
| **忘记退出旧账号导致演示冲突** | 按快捷键 `Ctrl + Shift + Delete` 清理浏览器 LocalStorage 并刷新，即可恢复初始状态。 |
