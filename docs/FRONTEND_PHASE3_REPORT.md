## 1. 实施范围与核心重构目标

本阶段旨在彻底摆脱传统开源项目「工程调试控制台」的刻板印象，参考 **ChatGPT** 与 **Claude** 等顶级成熟 AI 桌面产品的交互范式，打造专业、沉浸、企业级开箱即用的 AI 知识工作台：

- **左侧会话侧栏**: 收敛至标称 **260px**，支持按「今天」、「昨天」、「最近 7 天」、「更早」进行自然时间分组；
- **当前会话工具栏**: 将原挤占在侧栏中的「知识库选择器」上移至主聊天区顶部，同模式切换（⚡ 快速问答 / 🧠 深度分析）、模型选择器及附件状态融为一体；
- **消息阅读区域**: 确立 **840px 最大宽度水平居中容器**（`margin: 0 auto`），AI 回答铺展至完整宽度，用户消息靠右成组，间距与留白自然舒展；
- **底部输入区域**: 保持现有附件上传与解析底座功能，但在布局上严格对齐 840px 居中流；
- **响应式保障**: 重点适配 1920×1080 与 1366×768，确保任意分辨率下无横向滚动条、无内容裁切、无输入框跑飞。

## 3. 四大核心板块重构细节

### 3.1 会话侧栏（自然时间分组与极简管理）

- **空间尺寸**: 固定标称 `width: 260px, minWidth: 260px, maxWidth: 260px`，背景为清爽白（`#ffffff`），右侧边界为极细灰线（`1px solid #e2e8f0`）。
- **新建对话按键**: 高度提升至 `38px`，背景色采用企业交互蓝 `#2563eb`，微圆角 `8px`，轻量阴影 `0 1px 2px rgba(37,99,235,0.15)`。
- **自然时间分组**:
  - `今天` (Today): 统计今天 00:00 之后更新/创建的会话；
  - `昨天` (Yesterday): 统计昨天 00:00 至 23:59 的会话；
  - `最近 7 天` (Last 7 Days): 统计过去 7 天内活跃的会话；
  - `更早` (Older): 归档更早时期的会话。
  - 分组标题仅在组内存在会话时展示，采用微型字体（`11px, font-weight: 600, color: #94a3b8`）。
- **会话项微交互**:
  - 选中态：淡蓝底色 `#eff6ff` + 边界 `#bfdbfe` + 标题蓝 `#1d4ed8` + 加粗 `font-weight: 600`；
  - 悬停态：浅灰底色 `#f1f5f9`；
  - 删除按键：日常状态或未选中时透明隐藏，鼠标悬停即刻淡入，配合 Ant Design `Popconfirm` 气泡确认，杜绝误触。

### 3.2 当前会话工具栏（知识库与状态上移归位）

- **原设计痛点**: 知识库选择器原置于左下角侧栏，逻辑割裂；而右侧顶栏却常驻了一条很长的开发者管线文字，使页面显得笨重繁杂。
- **重构后顶栏**:
  - 高度锁定 `56px`，纯白底色，底部浅线分隔；
  - **左侧核心配置区**:
    - **知识库选择器**: 移入顶栏最左侧，带数据库小图标，支持检索/切换/清空；
    - **执行模式切换器**: `⚡ 快速问答`（Workflow RAG）与 `🧠 深度分析`（LangGraph Agent），模式说明折叠至 Tooltip 中；
    - **附件状态**: 当前会话存在附件时，自动展示蓝色轻量胶囊（如 `1 个附件已就绪`）。
  - **右侧模型配置区**:
    - 模型选择下拉框，准确标识默认模型、具备 `Tool` 调用能力的模型。

### 3.3 消息阅读区域（840px 居中沉浸阅读流）

- **流式居中容器**: 外层全屏滚动，内层统一嵌套 `maxWidth: 840, width: '100%', margin: '0 auto'`。
- **AI 助手消息**:
  - 占据 840px 完整横宽（`width: 100%`），纯白卡片底（`#ffffff`），极浅细边（`#e2e8f0`），软阴影（`0 1px 3px rgba(0,0,0,0.05)`）；
  - 左侧常驻蓝色现代 Robot 头像；
  - 完整呈现 Phase 2 的 `MarkdownRenderer`（加粗标题、语义表格、多语言代码块与一键复制）；
  - 正文中精准嵌入可悬停、可点击的 `[Ref-X]` 胶囊；
  - 底部保留事实依据聚合条与指标徽章（耗时、Token 预算、重排延时）。
- **用户消息**:
  - 靠右对齐（`justifyContent: 'flex-end'`），最大宽度为 840px 的 `75%`（约 630px），呈现自然的对话式气泡；
  - 皇家蓝背景 `#2563eb` + 纯白文字 `#ffffff`，圆角呈现 `16px 4px 16px 16px`。

### 3.4 响应式布局与视口溢出保护

- **1920×1080 桌面端**: 侧栏 260px 贴左，主内容区居中呈现 840px 阅读流，两侧留白均匀通透；
- **1366×768 笔记本端**: 侧栏 260px 贴左，剩余 1106px 中 840px 居中流自如容纳，顶栏工具无重叠折行；
- **窄屏（<900px）动态自适应**: `maxWidth: 840, width: '100%'` 自动收缩至全宽，杜绝水平滚动条。
