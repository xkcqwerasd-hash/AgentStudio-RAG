## 4. 路由与各功能模块无退化验证

本阶段虽然调整了顶栏排版，但**严格保证所有既有功能与页面路由 100% 完整可用**：

1. **智能知识问答 (`chat`)**:
   - 默认激活主页，支持点击 Logo 随时瞬时返回。
   - 聊天会话切换、模型选择、双模式切换、临时附件上传与问答链路完全不受影响。
2. **知识库管理 (`knowledge`)**:
   - 点击主导航直达知识库管理，支持文档上传、分块查看与知识库增删。
   - **联动跳转回归**: 知识库列表中的「调试检索」按钮触发 `handleNavigateToDebug(kb.id)`，平滑带参切入检索调试台。
3. **模型管理中心 (`models`)**:
   - 点击主导航直达模型管理，供应商配置、连接测试、默认模型设置正常工作。
4. **检索质量调试台 (`retrieval`)**:
   - 点击右侧「检索调试」按钮即刻呈现四路对比检索测试台；
   - 处于调试台时，主菜单自动清除无关选中态，右侧「检索调试」按钮呈现高亮激活态；
   - 再次点击任意主菜单均可顺畅返回业务界面。
